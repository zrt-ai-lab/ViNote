# 核心流程

Task API → NoteGenerator → 媒体/转录/优化/摘要/导图 → Markdown + SQLite。TaskStatus 是 UI 进度和产物文件名契约。

历史、标签、卡片和会话使用 SQLite；文件限定 TEMP_DIR。删除与重生成必须按笔记协调，不能保留文件却删除索引。问答绑定 1–5 条笔记，需要在预算内覆盖各来源及相关后段；摘要/卡片同样不能只读开头。

验证使用临时数据库/文件与假模型，另做启动和浏览器验收。真实模型质量、模型下载、Windows 安装需要独立证据。

## 当前职责

- `note_operations.py`：单进程内按笔记串行化清理和重生成，取消时等待提交/回滚结束。
- `note_search.py`：SQLite 正文缓存、FTS5 trigram 加速及无 FTS 时的兼容搜索；保存/重生成同事务刷新，启动只回填缺项。
- `qa_retrieval.py`：中文/英文词法召回、分来源预算和历史裁剪；不增加向量服务。卡片用均匀采样覆盖首中尾，不代表长文每个事实都会进入提示词。
- `ai_client.py`：默认 Whisper 延迟加载，可选 ASR 依赖分组安装，本地模型目录优先。
- `frontend_cache.mjs`：依赖和输入/输出内容哈希决定前端安装与构建是否可复用。
