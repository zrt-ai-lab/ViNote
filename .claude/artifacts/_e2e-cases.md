# E2E 用例

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 合集解析 | 粘贴 Bilibili/YouTube 合集地址并解析 | 展示可勾选条目，最多提交 20 条 |
| 非法合集地址 | 提交非白名单站点 | 返回 400，不发起外部解析 |
| 批量生成 | 勾选多个条目后生成 | 复用批处理任务，逐条可查看进度 |
| 空模型输出 | 优化或摘要模型返回空文本 | 自动使用基础清理或本地摘要，不生成空笔记 |
| 历史问答 | 选择 1 至 5 篇笔记创建会话并提问 | 回答流式展示，刷新页面后消息仍存在 |
| 重新生成 | 对历史笔记执行重做摘要或重做笔记 | 对应文件更新，历史详情立即刷新 |
| 旧数据库升级 | 用旧版 SQLite 启动 | 自动增加原始转录、降级提示字段与问答表，不丢失旧笔记 |
| 无 LLM 本地视频 | 未配置 OpenAI，提交带内嵌字幕的本地视频 | 任务完成并生成非空原文、整理稿和摘要，返回固定降级提示 |
| 完成状态回读 | 任务完成并从内存转入 SQLite 后，继续用完整任务 UUID 查询 | `warnings`、降级完成文案和 32 位笔记 ID 保持一致 |
| 任务产物清理 | 删除刚完成的任务存储 | 仅删除该笔记的原文、整理稿、摘要和翻译，不影响其他记录 |
