## 1. 背景与目标

在保持视频笔记、转录、问答、思维导图、下载和历史记录功能不变的前提下，修复已复现的接口状态错误、失效限流和不安全代理边界，并收敛重复的任务、流式连接和媒体输入逻辑。

## 2. 用户故事

| 角色 | 我想要 | 以便 | 优先级 |
|------|--------|------|--------|
| ViNote 用户 | API 返回准确状态和错误 | 能判断重试、缺失或服务异常 | P0 |
| ViNote 用户 | 批量与流式任务可稳定取消和恢复 | 长任务不会出现状态错乱 | P0 |
| 维护者 | 共用任务与媒体处理能力只有一套实现 | 后续新增功能不再复制错误 | P1 |

## 3. 范围

**本次做：** 修复限流、API 404、下载异常映射、图片代理边界；统一错误响应和任务状态；收敛前端 SSE；提取媒体输入公共流程；补充启动与回归验证。

**本次不做：** 用户认证、云端多租户、模型密钥管理、向量数据库和 UI 视觉改版。

## 4. 主流程

```text
请求边界校验 → 单一任务状态 → 统一媒体输入 → 业务产物生成 → SQLite/文件产物 → SSE/REST 展示
```

## 5. 数据与接口契约

| Scope | 实体/接口/字段 | 类型 | 说明 |
|-------|----------------|------|------|
| backend | HTTP 错误 | JSON | 保留原 detail，并返回正确 4xx/5xx |
| backend | 任务状态 | 内存 + SQLite | 持久状态以数据库为准，运行句柄保留内存 |
| shared | SSE | text/event-stream | 统一解析、关闭和错误回调 |
| backend | 媒体输入结果 | 内部对象 | 标题、转录、来源和临时文件清理信息 |

## 6. 异常与边界

| 场景 | 预期处理 |
|------|----------|
| 不存在的 `/api/*` | JSON 404，不返回 SPA HTML |
| 下载任务或文件不存在 | 保持 404，不被转成 500 |
| 图片指向内网、非图片或体积超限 | 400/413/502，且不读取完整响应到内存 |
| LLM 降级 | 任务完成但带 warning，不伪装成纯 AI 成功 |
| SSE 中断 | 释放连接；任务本身继续，页面可重新连接查询状态 |

## 7. 验收标准

| ID | 验收项 | 可观察判据 |
|----|--------|------------|
| AC-CS-001 | 接口状态正确 | 限流可触发；未知 API、缺失下载均返回对应状态 |
| AC-CS-002 | 边界受控 | 图片代理拒绝内网、非图片和超限响应 |
| AC-CS-003 | 状态一致 | 取消、批量和完成任务不会因多套状态产生矛盾 |
| AC-CS-004 | 无功能回归 | Python 编译、前端构建、启动 smoke 和核心 API 通过 |

## 需求审视

- 根本问题：新增能力沿页面和路由横向复制，导致错误处理与状态来源分叉。
- 隐含假设：兼容现有 API 比一次性重写更重要。
- 更小方案：先修复可复现错误，再逐层提取公共服务，不改变用户入口。
- 复杂度边界：不引入外部队列、数据库或桌面框架。
