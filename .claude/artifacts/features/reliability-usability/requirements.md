# ViNote 可靠性与使用体验

用户已采纳审查建议；不更换框架、不移除业务能力、不增加外部向量服务、不提交私人配置。

- AC-1：中英长段落、无标点、末句分段不丢正文。
- AC-2：按年龄清理只删除候选笔记；异常保留文件和记录；重生成失败保留旧产物。
- AC-3：任务返回真实下载文件名，下载失败不提示成功。
- AC-4：问答召回多来源及相关后段；摘要请求有界；卡片材料抽样覆盖首、中、尾，不再只取开头。
- AC-5：刷新/切换/断网恢复任务和批次；会话可列出、继续、删除。
- AC-6：搜索标题、正文、摘要，旧记录回填；筛选分页保持兼容。
- AC-7：默认不强制可选 ASR 依赖；Windows 脚本可继续执行；避免不必要 npm ci。
- AC-8：开发回归与 CI，不把测试/私人配置/模型缓存打入运行包。

EXE 是独立交付需求，需 Windows 构建实测；本轮先优化启动和依赖，不宣称有可用 EXE。
