# ViNote 2.0 规格

## 产品

ViNote / Video to Everything

2.0 是一次换代版本，不承诺旧页面、旧 API、旧文件结构兼容。旧代码只作为迁移参考，不能继续进入运行时。

## 核心闭环

导入视频、音频、字幕或 URL -> MediaAsset -> ProcessingJob -> TranscriptSegment -> Summary、Translation、Mindmap、Flashcard、QA Artifact -> 搜索、引用、复习、导出

## 一级产品

- 工作台：导入、最近资产、失败任务、待复习。
- 知识库：资产列表、全文搜索、主题集合。
- 资产详情：播放器、时间轴 transcript、摘要、问答、高亮、卡片、导图、导出。
- 设置：模型、ASR、存储、导入目录和高级诊断。

## 过期功能

- 独立视频笔记、问答、导图、卡片页面。
- 独立下载/预览产品入口。
- DevTools 和 Cookie 转换页面。
- ANP 作为默认运行时依赖。
- tasks.json 运行时状态。
- 通过 Markdown 文件名和标题找回资产。

## 验收门槛

- 服务重启后任务不会伪装成 processing；
- SSE 断线后可通过任务快照恢复；
- 同一个 asset 只产生一次 transcript；
- 摘要、问答和卡片都能返回 transcript segment 引用；
- 删除资产不会误删其他资产内容；
- 本地文件只能上传或位于配置的 import root；
- 默认服务只绑定本机；
- 2.0 发布包不包含私钥、Cookie、旧开发辅助文件和已废弃页面。
